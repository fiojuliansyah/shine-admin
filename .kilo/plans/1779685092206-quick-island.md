# Plan: Ganti TinyMCE dengan Fabric.js Editor (DOCX-like)

## Tujuan
Mengganti editor TinyMCE pada halaman `create` dan `edit` letter dengan editor berbasis **Fabric.js** yang memberikan pengalaman seperti mengedit dokumen DOCX — canvas A4 multi-halaman, teks editable langsung, drag & drop elemen, toolbar formatting, dan insert variable langsung ke canvas.

---

## Analisis Kondisi Saat Ini

- Editor: **TinyMCE** (loaded dari `/admin/assets/libs/tinymce/tinymce.min.js`)
- Data disimpan sebagai HTML di kolom `description` (TEXT) di tabel `letters`
- Form submit via POST biasa ke `letters.store` / `letters.update`
- Fitur: custom variables, copy variable ke clipboard
- Layout: `@push('js')` dan `@stack('js')` tersedia di `main.blade.php`
- Fabric.js **belum ada** di project

---

## Keputusan Desain (berdasarkan jawaban user)

| Topik | Keputusan |
|-------|-----------|
| Data letter lama (HTML) | Konversi otomatis: saat edit, HTML diparse jadi satu Textbox di canvas |
| Insert variable | Klik variable langsung insert Textbox ke canvas |
| Multi-halaman | Ya — tambah/hapus halaman, tiap halaman = canvas terpisah |

## Arsitektur Editor

### Struktur Data (disimpan di `description`)
```json
{
  "pages": [
    {
      "id": 1,
      "canvasJSON": { "objects": [...], "background": "#fff" }
    },
    {
      "id": 2,
      "canvasJSON": { "objects": [...], "background": "#fff" }
    }
  ]
}
```

### Multi-halaman
- Setiap halaman dirender sebagai `<canvas>` terpisah dalam container scroll
- Halaman aktif (yang sedang diedit) di-highlight
- Toolbar "Tambah Halaman" dan "Hapus Halaman" tersedia
- Saat switch halaman, state canvas halaman sebelumnya di-serialize ke array `pages`

### Konversi HTML Lama
Saat `edit.blade.php` load dan `description` bukan JSON valid (tidak ada key `pages`), maka:
- Buat 1 halaman baru
- Buat satu `fabric.Textbox` berisi teks plain dari HTML (strip tags)
- Posisi: top-left canvas

### 3. JavaScript: FabricEditor Class

Logika editor dikemas dalam satu object/class `FabricEditor`:

```js
class FabricEditor {
  constructor() {
    this.pages = [];       // array of { id, canvas, historyUndo, historyRedo }
    this.currentPage = 0;
    this.CANVAS_W = 794;
    this.CANVAS_H = 1123;
  }

  init(savedData) { ... }         // parse savedData JSON atau HTML lama
  addPage() { ... }               // tambah halaman baru
  deletePage(index) { ... }       // hapus halaman
  switchPage(index) { ... }       // aktifkan halaman
  serializeAll() { ... }          // return JSON string semua halaman
  loadFromJSON(data) { ... }      // load dari JSON tersimpan
  convertFromHTML(html) { ... }   // konversi HTML lama → Textbox
  insertVariable(code) { ... }    // insert Textbox variabel ke canvas aktif
  addText() { ... }               // tambah Textbox kosong
  addImage(file) { ... }          // tambah gambar dari file input
  deleteSelected() { ... }        // hapus objek terpilih
  applyFormat(prop, value) { ... } // apply bold/italic/dll ke selection
  undo() { ... }                  // undo history
  redo() { ... }                  // redo history
  renderThumbs() { ... }          // render thumbnail halaman di #pageThumbs
}
```

### 4. Undo/Redo
Setiap perubahan canvas (`object:added`, `object:removed`, `object:modified`) menyimpan snapshot `canvas.toJSON()` ke array `historyUndo`. Max 30 snapshot per halaman.

### 5. Konversi HTML Lama (edit.blade.php)
```js
convertFromHTML(html) {
  const text = html.replace(/<[^>]+>/g, ' ').replace(/\s+/g, ' ').trim();
  const tb = new fabric.Textbox(text, {
    left: 50, top: 50,
    width: this.CANVAS_W - 100,
    fontSize: 14,
    fontFamily: 'Arial',
    fill: '#000'
  });
  this.pages[0].canvas.add(tb);
}
```

### 6. Insert Variable ke Canvas
Fungsi `copyVar(val)` diubah menjadi `insertVar(val)`:
```js
insertVar(val) {
  const tb = new fabric.Textbox(val, {
    left: 100, top: 100,
    fontSize: 14,
    fontFamily: 'Arial',
    fill: '#0d6efd',
    fontStyle: 'italic'
  });
  this.pages[this.currentPage].canvas.add(tb);
  this.pages[this.currentPage].canvas.setActiveObject(tb);
}
```

### 7. Submit Form
```js
document.getElementById('letterForm').addEventListener('submit', function(e) {
  const json = editor.serializeAll();
  if (!json) { e.preventDefault(); alert('Konten surat tidak boleh kosong.'); return; }
  document.getElementById('descriptionHidden').value = json;
});
```

### 8. show.blade.php — Read-only Render
- Load Fabric.js
- Parse JSON dari `$letter->description`
- Render tiap halaman sebagai canvas read-only (`canvas.selection = false`, semua objek `selectable: false, evented: false`)
- Jika bukan JSON valid (data HTML lama), tampilkan sebagai HTML biasa (fallback `{!! $letter->description !!}`)

## Catatan Risiko

- Fabric.js canvas tidak bisa di-print langsung seperti HTML; jika ada fitur print/PDF perlu `fabric.Canvas.toDataURL()` atau library tambahan (tidak dalam scope ini)
- Data lama yang dikonversi otomatis kehilangan formatting HTML (bold, tabel, dll) — hanya teks plain yang diambil
