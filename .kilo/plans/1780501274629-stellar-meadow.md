# Plan: Konfigurasi NIK Karyawan per Company

## Goal

Tambah fitur konfigurasi format NIK Karyawan per Company. Mirip dengan
Letter Number Configuration yang sudah ada. Setiap company bisa punya
beberapa konfigurasi NIK (preset), satu di-default. Saat generate
offering / pemberkasan, NIK karyawan dibentuk dari config milik company
yang dipilih, dengan counter sequential per-company yang persistent.

## Decisions (dari pertanyaan)

- Storage: tabel terpisah `employee_nik_configs` (FK ke `companies`).
- Token tanggal join: 2/4 digit standar (`{tanggal_join}`, `{bulan_join}`,
  `{tahun_join}`, `{tahun_join_pendek}`).
- Counter scope: per-company sequential. Disimpan di kolom `current_number`
  pada record konfigurasi yang aktif.
- Fallback: WAJIB config. Jika company target belum punya config, generate
  offering / document-digital diblokir dengan error message yang
  mengarahkan ke menu konfigurasi.

## Token yang Tersedia

| Token | Sumber | Contoh |
|---|---|---|
| `{no}` | counter sequential, di-pad sesuai `padding` | `00007` |
| `{prefix}` | field `prefix` di config | `EMP` |
| `{kode_jabatan}` | `user->roles()->first()->code` (fallback `XX`) | `SEC` |
| `{kode_company}` | `companies.unique_id` | `CK` |
| `{tanggal_join}` | `applicant.start_date` → `dd` | `15` |
| `{bulan_join}` | `applicant.start_date` → `mm` | `05` |
| `{tahun_join}` | `applicant.start_date` → `YYYY` | `2026` |
| `{tahun_join_pendek}` | `applicant.start_date` → `yy` | `26` |

## Files / Changes

### 1. Migration baru

`database/migrations/2026_06_03_<ts>_create_employee_nik_configs_table.php`

```php
Schema::create('employee_nik_configs', function (Blueprint $table) {
    $table->id();
    $table->foreignId('company_id')->constrained('companies')->cascadeOnDelete();
    $table->string('name');                  // label preset
    $table->string('format');                // pakai token di atas
    $table->string('prefix')->nullable();
    $table->unsignedSmallInteger('padding')->default(5);
    $table->unsignedInteger('start_number')->default(1);
    $table->unsignedInteger('current_number')->default(0);
    $table->boolean('is_default')->default(false);
    $table->text('description')->nullable();
    $table->timestamps();

    $table->unique(['company_id', 'name']);
});
```

Concurrency note: increment `current_number` dengan
`DB::transaction()` + `lockForUpdate()` agar dua request tidak
kebagian nomor sama.

### 2. Model `app/Models/EmployeeNikConfig.php`

- `protected $guarded = []`
- relasi `company()` → `belongsTo(Company::class)`
- method `generateNik($user, $startDate)`:
  - Resolve token dari context user + start_date + company.
  - Lakukan `DB::transaction` → `lockForUpdate` ambil row → hitung
    `next = max(current_number + 1, start_number)` → simpan
    `current_number = next` → return string NIK formatted.
- method statis `defaultForCompany($companyId)` ambil yang
  `is_default = true`, fallback ke yang pertama.
- guard: jika `is_default` di-set, controller harus reset siblings.

### 4. Controller `app/Http/Controllers/EmployeeNikConfigController.php`

Resource controller (mirror `LetterNumberConfigController`):

- `index()` → list konfigurasi grouped by company; modal create/edit.
- `store(Request)` → validate company_id, name unique per company,
  format required. Kalau `is_default = 1`, set siblings ke 0 dalam
  transaction.
- `update($id)` → idem, plus jangan reset `current_number` (preserve).
- `destroy($id)` → block kalau ini satu-satunya config + ada referensi.
- `preview(Request)` → JSON endpoint untuk live preview di form
  (tidak menyentuh `current_number`, pakai dummy sequence = 1).

### 8. Integrasikan ke flow generate NIK

Lokasi pemakaian saat ini: `app/Http/Controllers/StatusController.php`
function `bulkUpdateApplicantDocument` (~line 195) dan
`bulkUpdateOffering` (~line 272). Keduanya membentuk
`$employeeNIK = $companyCode . $roleCode . $monthJoinCode . $yearJoinCode . str_pad(...)`.

Ganti dengan:

```php
$site = Site::with('company')->find($site_id);
if (!$site || !$site->company) {
    return redirect()->back()->with('error',
        'Site/Company tidak valid.');
}

$config = EmployeeNikConfig::where('company_id', $site->company_id)
    ->where('is_default', true)
    ->first()
    ?? EmployeeNikConfig::where('company_id', $site->company_id)->first();

if (!$config) {
    return redirect()->back()->with('error',
        'Company "' . $site->company->name . '" belum memiliki konfigurasi NIK Karyawan. ' .
        'Silakan atur di menu Konfigurasi NIK.');
}

$employeeNIK = $config->generateNik($applicant->user, $request->start_date);
```

Catatan: existing `each()` callback me-return tidak abort outer
loop. Saya ganti pre-validation di luar loop: jika ada applicant
yang site→company-nya tidak punya config, redirect back lebih awal
sebelum loop jalan, agar tidak ada NIK partial.
